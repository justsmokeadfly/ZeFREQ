# ZeFREQ — Human Frequency

Official concept website for the electronic duo **ZeFREQ**, featuring Soul, Industrial and Drum & Bass.

## Website

Static bilingual site (Russian/English), no build tools, npm packages or backend required. All files live in repository root, ready for GitHub Pages.

## Deployment

**Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.**

Public URL, after Pages activation: https://justsmokeadfly.github.io/ZeFREQ/

## Asset status

The original photo-based website was designed with generated portraits of the two vocalists. Due to upload limitations, this initial repository version contains original **SVG character artwork** instead of the full-resolution photographic assets. These can later be replaced under `assets/` without changing the HTML layout. Do not represent this artwork as a real photograph.

## Release status

"Тепло в проводах" is in preparation. The displayed platforms are planned distribution targets, not active streaming links. No fictional release dates or social media accounts.
